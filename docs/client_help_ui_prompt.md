# Промпт: «Справка»→«Помощь» + гайд по работе бота + гайд по регистрации

Для workflow `.claude/agents/workflow.md` (planner → researcher →
implementer → test-expert → reviewer). Три маленькие независимые
UI-задачи, только клиентская сторона — админскую «Справку» не трогать.

## 1. Переименовать "❓ Справка" → "❓ Помощь" (только клиент)

Затронуть только client-путь, найденный через
`grep -rn "Справка" bot` (перепроверить актуальность):
`bot/keyboards/client/client_main_keyboard.py` (кнопка),
`bot/handlers/common/help.py` (клиентский матчер `F.text.in_({...})`),
`bot/utils/info.py` (`show_main_client_menu` / `display_client_help_msg`
— текст "нажмите Справка" тоже переименовать). Админскую ветку
(`admin_main_menu_kb.py`, `display_admin_help_msg`, `show_main_admin_menu`)
не трогать.

## 2. Кнопка "🧭 Как бот работает" в клиентской "Помощи"

В `display_client_help_msg` (`bot/utils/info.py`) добавь inline-кнопку
под текстом справки, callback → новый хендлер (в `help.py` или рядом),
который отправляет текст ниже (можно адаптировать формулировки, но
сохранить структуру и шаги — этот текст в будущем ляжет в основу
инфографики-гайдфлоу, поэтому порядок шагов менять нельзя):

```
Как это работает:

1️⃣ «📋 Управление записями» → «Записаться на приём».
2️⃣ Выбираете врача, день и свободное время, коротко описываете причину визита.
3️⃣ Заявка уходит в клинику: администратор подтверждает, отклоняет
    или предлагает другое время.
4️⃣ Если предложено новое время — соглашаетесь или отклоняете прямо в чате.
5️⃣ Когда запись подтверждена, бот пришлёт напоминания за 24ч и за 2ч
    до приёма с кнопками «Приду» / «Не приду».
6️⃣ Перенести или отменить запись можно в «Управлении записями» в любой
    момент, кроме последнего часа перед приёмом.
```

## 3. Кнопка "❓ Как пройти рег" на экране регистрации

В `bot/handlers/registration.py`, у сообщения "Пройдите регистрацию для
дальнейшего взаимодействия." (строка ~61), добавь inline-кнопку,
открывающую текст ниже. Обязательно подчеркнуть в тексте, что номер
отправляется кнопкой `contact_keyboard()` ("📱 Отправить контакт",
`request_contact=True`), а не вводится вручную — это единственный
поддерживаемый способ:

```
Как пройти регистрацию:

[Открыли ссылку/QR клиники]
        │
        ▼
   Бот просит контакт
        │
        ▼
 Жмите кнопку "📱 Отправить контакт"
    (номер вручную НЕ вводите!)
        │
        ▼
  Бот находит вашу карту
     или заводит новую
        │
        ▼
    Подтвердите ФИО
        │
        ▼
       Готово ✅
```

## Порядок и Definition of Done

researcher находит все текущие вхождения "Справка" и точное место
сообщения о регистрации → implementer добавляет кнопки/хендлеры и
тексты выше → test-expert прогоняет/дополняет тесты хендлеров
(`help.py`, `registration.py` — есть готовые тесты рядом, расширить их,
не дублировать) → reviewer сверяет с CLAUDE.md (кнопки — в keyboards,
никакой бизнес-логики в хендлере, кроме отправки текста).

Готово, когда: у клиента везде "Помощь" вместо "Справки", у админа
ничего не изменилось; в клиентской "Помощи" есть рабочая кнопка с
текстом из п.2; на экране регистрации — рабочая кнопка с текстом из
п.3; `pytest` зелёный.
